# Netflix Content Analysis

## Objective
Analyze Netflix content to identify trends in content types, countries, genres, and release years.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Insights
1. Netflix contains 6,131 Movies and 2,676 TV Shows.
2. United States contributed the most content (2,818 titles).
3. India is the second-largest contributor (972 titles).
4. 2018 had the highest number of releases (1,147 titles).
5. Drama and International Movie combinations were among the most common genres.
